# 해방 게임 — Unity 바이브 코딩 행동강령 패키지

## 설치 방법
1. 압축 파일을 **Unity 프로젝트 루트**에 풀어 `AGENTS.md`, `DECISIONS.md`, `agents/`, `contracts/`, `prompts/`를 둔다.
2. 현재 대화에서 만든 기존 장별 기능명세서 원본 `.md` 파일은 프로젝트 루트의 `docs/`에 복사한다. 이 패키지에는 모든 과거 기획문서를 중복 포함하지 않았다.
3. AI에게 **공통 AGENTS.md + 해당 담당 agents/*.md + 관련 기획문서**를 읽히고 1회 요청에는 한 기능만 구현하도록 요청한다.
4. `contracts/INTERFACES.md`의 C# 타입/이벤트 명은 **구현 제안**이므로 현재 프로젝트 구조와 비교해 먼저 확정한다.
5. `ROADMAP.md` 순서로 세로 슬라이스를 구현하고 확인한다.

## 파일 구성
- `AGENTS.md`: 모든 AI가 따라야 하는 공통 행동강령
- `DECISIONS.md`: 1~5장 확정 결정과 기술 제약
- `agents/`: 14개 전담 행동강령
- `contracts/INTERFACES.md`: 모듈 이벤트·저장 데이터·소유권 경계
- `prompts/`: 복사해서 쓰는 작업 요청 템플릿과 샘플
- `ROADMAP.md`: 실제 개발 의존 순서

## 중요한 주의
게임 스토리·퀘스트의 **확정 사항**과 AI가 제시한 **구체 구현 제안**은 구분한다. 온라인의 로컬 우선 UX와 서버 거래 소유권 검증은 완전하게 합의된 기술 설계가 아니므로 독립 검토가 필요하다.
